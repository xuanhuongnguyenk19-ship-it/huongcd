# Tín Đức ERP – bản demo

Bản demo giao diện hệ thống quản trị cho doanh nghiệp sản xuất LVL/Plywood, gồm các module Sản xuất, Kho, Tài chính – Kế toán, Nhân sự, Dashboard và Quản trị.

- Mở `index.html` bằng trình duyệt là dùng được, không cần cài đặt.
- Ở góc trên, ô **Đăng nhập thử** cho phép đổi vai trò (nhân viên, quản đốc, thủ kho, kế toán trưởng, giám đốc, admin…) để thử quy trình duyệt.
- Tên nhân viên trong bản demo là tên mẫu.
- Dữ liệu chỉ lưu trên trình duyệt của từng người. Muốn quay về dữ liệu ban đầu: đăng nhập thử bằng **Admin** → Quản trị → Quy trình duyệt & đơn giá → "Khôi phục dữ liệu mẫu ban đầu".
